# 🎓 Intelligent Tutoring System (ITS)

An AI-powered **Intelligent Tutoring System (ITS)** built using the **MERN Stack** that delivers a personalized learning experience by assessing students' knowledge, classifying their proficiency, and recommending tailored learning resources. The platform combines modern web technologies with machine learning techniques to create an adaptive and scalable educational solution.

---

## 🚀 Features

* 👨‍🎓 Student Registration & Secure Authentication
* 📚 Personalized Learning Recommendations
* 📝 MCQ-Based Student Assessment
* 🧠 Student Proficiency Classification using Machine Learning
* 📈 Progress Tracking & Performance Monitoring
* 🎯 Adaptive Learning Paths
* 💾 Cloud-Based Database Storage
* 📱 Responsive and User-Friendly Interface

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/intelligent-tutoring-system.git
```

### Navigate to the project

```bash
cd intelligent-tutoring-system
```

### Install dependencies

#### Frontend

```bash
cd client
npm install
npm start
```

#### Backend

```bash
cd server
npm install
npm run dev
```
